# Claude Code for Everyone

Beginner course resources from Mark Kashef and Prompt Advisers.

## Start here

**[Open the learner hub](https://promptadvisers.github.io/claude-code-for-everyone/)** for the prompts, starter downloads, checks and working examples.

You do not need Git commands, an IDE or a GitHub account. Install [Claude Desktop](https://claude.com/download), sign in, and confirm your account has the Code tab.

1. Download the starter ZIP for the exercise below.
2. Unzip it into a normal folder.
3. In Claude Desktop, select **Code**, a local environment, and that unzipped folder.
4. Start in **Plan** to read and discuss. Switch to **Manual** when you are ready to approve changes.

| Exercise | Download | Folder to choose in Code |
|---|---|---|
| First request | [Starter ZIP](downloads/00-workspace-tour.zip) | `workspace-tour` |
| Workshop website | [Starter ZIP](downloads/01-client-site.zip) | `01-client-site` |
| Meeting board and skill | [Starter ZIP](downloads/02-meeting-board.zip) | `02-meeting-board` |
| Regional dashboard | [Starter ZIP](downloads/03-operations-dashboard.zip) | `03-operations-dashboard` |
| Repair practice | [Starter ZIP](downloads/04-dashboard-repair.zip) | `04-dashboard-repair` |

Keep a clean copy and work in a duplicate. The repair starter deliberately contains an incorrect calculation.

## Repository layout

- `workspace-tour/`: three small files for the first read-only request
- `demos/*/starter/`: starting files
- `demos/*/completed/`: worked examples
- `demos/*/checkpoint/`: working recovery copies
- `demos/02-meeting-board/reusable-skill/`: the full tested skill, in its hidden `.claude` folder
- `downloads/`: individual starter ZIPs; hidden folders are preserved

To download everything at once, use the green **Code** button on this page, then **Download ZIP**. Unzip and open `START-HERE.html`. The smaller exercise ZIPs are easier when following the course.

This is the introductory course. [Claude Code for Everyone — Next Steps](https://github.com/promptadvisers/claude-code-next-steps) is a separate follow-on course.

The repository contains learner materials only. Instructor notes, private review logs, research transcripts and production sources are not included.
