Prompts in classroom order

19. First, ask Claude to look

Code · workspace-tour folder · T01

Look at the files in this folder. Explain what each one is for in plain English. Do not change anything yet.

Check: README.md, workshop-brief.md and welcome-note.md; no changes.

43. First, confirm the job

Code · 01-client-site · Plan mode · D01-READ

Read the approved workshop offer and FAQ. Explain who the website is for, which workshop options it must show, and what visitors should be able to do. Do not build anything yet.

Check: The answer identifies the visitor, options and enquiry behaviour.

44. Then build the workshop page

Same project · switch to Manual, then approve the build · D01-P1

Build the workshop website we just discussed. Help a team lead compare the two options and prepare an enquiry. The form should check required fields and download the enquiry without sending it. Preserve the source files. Open the page and check the prices, form and phone layout.

Check: Prices match; the form validates and saves an enquiry locally.

46. Your turn: improve the comparison

same workshop project · D01-L1

Make the workshop comparison easier for a team lead to scan. Keep the approved prices and accessibility information. Test a missing email, a completed enquiry and a phone-sized view.

Check: The page is easier to scan and the original checks still pass.

66. Make the first meeting board

Code · 02-meeting-board · Manual mode · D02-P1

Turn the agreed actions in meeting A into a browser work board. Show each task’s owner, due date and source. Use explicit corrections; leave unknown details blank. Keep proposals separate from agreed work and preserve the original meeting. Show one task traced to its source.

Check: Four agreed actions; the corrected date is June 12.

67. Update one task with new information

Same meeting project · D02-L1

The onboarding guide now belongs to Owen and is due June 15, 2026. Record this as a new clarification, then update that task. Keep the original meeting and the other tasks unchanged. Show what changed.

Check: Owen · June 15 · separate clarification · other tasks unchanged.

69. Save that method as a skill

Same project · approve the SKILL.md write when asked · D02-P2

Save this meeting-to-task method as a project skill called meeting-to-work. Keep its steps reusable: read the rules, extract agreed actions, preserve sources and flag unknowns. Keep this meeting’s names and dates in the inputs. Include a success checklist.

Check: Find SKILL.md; it contains reusable steps and a checklist.

71. Try it on another meeting

New conversation · same folder · Manual mode · D02-P3

Use /meeting-to-work on meeting B. Put its results in a separate folder. Check that every task and source comes from this meeting. Leave unresolved owners or dates blank.

Check: Three active tasks; cancelled banners excluded; an unknown date stays blank.

79. Ask for the plan first

Code · 03-operations-dashboard starter · Plan mode · D03-P1

Plan a dashboard that shows approved order value by region. First explain which source rows count and how you will check the totals. Include a region filter, an empty state and an export of the visible rows. Do not build yet.

Check: The plan explains the metric and the checks before building.

80. Build the agreed dashboard

Same project · switch to Manual, then approve the build · D03-P2

Build the agreed dashboard using the supplied design reference. Preserve the source data and definitions. Open the result. Check the totals, region filter, empty state and export against the source rows.

Check: All 4,300 · North 1,700 · a useful empty state for West.

83. Ask for a focused repair

Code · 04-dashboard-repair · Manual mode · D03-P3

This prepared dashboard includes cancelled and draft orders in approved value. Find the cause and correct it. Keep the filter, layout and export working. Check that All is 4,300 and North is 1,700, then check the exported rows.

Check: The value is fixed; filters and export still work.

84. Your turn: make the count clear

Same repaired dashboard · D03-L1

Make approved order count clear beside approved order value. Add it if missing; otherwise check the existing count. State what it includes and make it follow the region filter. Verify All, North and the empty region without breaking value or export.

Check: All 5 · North 2 · West 0, with the definition visible.

88. Write the next request

YOUR OWN WORKFLOW · TRANSFER

I want to improve [a recurring task] for [the person using the result]. Read [the source material] and propose a short approach first. Create [a specific result]. Preserve [what matters]. Ask about missing information. We will check it by [an observable test].

Check: Every bracket becomes a concrete person, input, result or check.
