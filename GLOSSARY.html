Plain-English glossary

Folder

A place that holds the files for one job. The starter ZIP expands into a folder.

Session

One conversation with Claude Code, using its selected working folder.

Model

The AI doing the reasoning and writing.

Harness

The working setup around the model: files, tools, context and permission controls.

Markdown (.md)

An ordinary text document with simple headings and lists.

YAML

A format for settings written as labels and values. A skill uses it for the small header at the top.

CSV

A plain-text table: one row per record, with values separated by commas. Our orders file uses this format.

JSON

A structured text file for named values. The workshop page downloads the enquiry in this format. You do not have to write it.

Metric

A number with a clear definition, such as the total value of approved orders.

Checkpoint

A saved working version you can return to. It is a backup, not a promise that every action can be undone.

Repository (repo)

A shared collection of files. This GitHub repository is where the course materials live. You can download them without learning Git.
